# Publish free with GitHub Pages

Do not paste the HTML source into LinkedIn. LinkedIn should contain a short post, the case-study PDF, and a link to the hosted interactive demo.

## GitHub setup

1. Create a new **public** GitHub repository, for example `municipal-finance-control-layer`.
2. Upload the complete contents of this folder to the repository root.
3. In the GitHub repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. GitHub will provide a free URL similar to:
   `https://YOUR-USERNAME.github.io/municipal-finance-control-layer/`

The root `index.html` is already the interactive demo, so no build service, paid hosting, or domain purchase is required.

## LinkedIn publishing

Use LinkedIn for discovery and GitHub Pages for the interactive experience:

1. Upload the PDF from `case-study/` as a LinkedIn document/carousel post.
2. Explain the municipal-finance problem and the governed control-layer approach.
3. Add the GitHub Pages demo link.
4. Add the GitHub repository link for readers who want the public architecture and governance documentation.

## Before making the repository public

- Confirm the repository contains only the files in this public package.
- Do not upload private validation folders, accounting exports, bank records, source manifests, local paths, credentials, or QuickBooks company files.
- Keep the repository without an open-source license unless and until you intentionally choose licensing terms.
